**Button** — the primary action control; zero-radius, condensed uppercase label, flat (no shadow).

```jsx
<Button variant="primary" size="md" onClick={save}>Guardar</Button>
```

Variants: `primary` (solid blue), `secondary` (ink outline), `ghost` (text only), `inverse` (white, for dark/blue backgrounds), `danger` (error outline). Sizes: `sm` / `md` / `lg`. Use `block` to fill width. Labels are always uppercase — keep them short and imperative (Guardar, Exportar, Subir Excel).
