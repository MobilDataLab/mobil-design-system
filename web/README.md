# Web

Componentes React consumidos vía bundle compilado (`_ds_bundle.js`, namespace `MobilArquitectosDesignSystem_8d3ff0`).

- `components/forms/` — Button, IconButton, Input, Select, Checkbox, Radio, Switch
- `components/feedback/` — Badge, Tag, Callout, Banner
- `components/data/` — Card, KpiTile, StatBar, Tabs
- `ui_kits/mobil-carga/` — dashboard de carga re-expresado en v3

Requiere `../styles.css` cargado antes del bundle.

Iconos: set propio de trazo 1.5px (`ui_kits/mobil-carga/Icons.jsx`); para más cobertura, Lucide.
