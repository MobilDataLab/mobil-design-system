# Presentaciones

Layouts de referencia a 1920×1080:

- `slide-cover.html` — portada
- `slide-section.html` — separador de sección
- `slide-data.html` — slide de datos
- `slide-fullbleed.html` — foto a sangre con título

Reglas del medio:
- Texto nunca menor a 24px a 1920×1080.
- Máximo 1–2 colores de fondo por presentación (blanco, azul `#006BFF`, ink).
- Títulos en Swis721 Cn, mayúsculas, alineados a la izquierda.
- Cierre de sección con barra de 4px azul o amarilla.
