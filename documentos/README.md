# Documentos

Capítulo en preparación. Destino de las plantillas Word/PDF de la oficina (carta de honorarios, informes, EETT, memorias).

Reglas del medio:
- Texto mínimo 12pt en impresión.
- Tipografía: Swis721 Cn para títulos, Roboto para cuerpo; en Word sin las fuentes instaladas, usar Archivo Narrow / Roboto.
- Colores desde `../tokens/tokens.json`. En impresión, amarillo = Pantone 3945 C.
